# 云数据库索引

索引声明保存在 `cloud/database-indexes.json`。当前微信开发者工具 CLI 只提供环境和云函数命令，没有数据库索引部署命令，因此索引需要在云开发控制台的“文档型数据库 → 集合 → 索引管理”中按声明创建。

优先创建 `pet_shared_records.scope_key`。共享记录读取按 `scopeId + key` 查询；缺少该组合索引时，数据量增长后会退化为全表扫描。其余索引覆盖共享档案、成员查询和邀请码校验。

字段顺序和方向必须与声明一致。部署后使用两个微信账号分别新增记录，再进入“数据保存状态”确认同步预览能在合理时间内返回。

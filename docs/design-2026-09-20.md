# 界面统一与记录管理调整

## 本轮修改

- 体重、纪念日、护理日历与设置、家庭共享、相册、用品表单统一使用中性色背景与陶土色操作按钮；相册照片上的渐变遮罩保留，用于保证日期可读。
- 提高二级页面小字号，减少重阴影与过粗字重；历史记录、家庭成员和共享说明允许换行。
- 弹层限制最大高度并允许滚动；小屏记录表单使用单列，关闭按钮扩大点击范围，输入框设置键盘间距。
- 日常记录的搜索、成员筛选和批量操作收进“管理”，已生效的筛选始终展示清除入口，只读成员不提供批量入口。
- 修复筛选列表导致当日总计变化的问题；筛选成员已不存在时恢复“全部成员”，成员选择器保持正确索引。
- 将“肠胃模型还在学习”等描述替换为记录数量与汇总条件。
- 清除首页废弃布局规则和部分重复覆盖声明，将压缩成整行的页面样式整理为逐条规则；保留媒体条件与级联顺序。

# 四入口导航

定位：宠物日常记录与家庭照护工具。

| 导航 | 内容 |
| --- | --- |
| 今天 | 今日概况、快捷记录、待办、日常提示 |
| 记录 | 喂食、饮水、排便、散步总览，原有记录详情与趋势，体重趋势，就诊资料入口 |
| 照护 | 护理日历、历史与提醒设置，用品余量，养护问答 |
| 我的 | 宠物档案、相册、家庭共享、数据与就诊资料 |

## 实现

- 保留 feed 作为非 Tab 详情路由，确保已有带日期/类型的跳转及补记入口继续可用。
- chat 改为照护下的普通页面，原有聊天记录不迁移、不清空，使用原生返回导航。
- 我的与照护共用 `pages/shared/account-controller.js` 工厂，每个页面创建独立状态，避免复制保存、权限与日期处理逻辑。
- 首页护理待办通过一次性 Tab 目标打开对应项目；记录页更新体重打开我的原有编辑弹层，取消或保存后再次进页不会重复打开。
- 体重计算、弹层与样式抽取共用；空记录不生成无穷数范围。

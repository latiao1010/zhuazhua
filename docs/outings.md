# 带狗出门

入口：首页「带狗出门」。页面在 `packages/outings` 分包中，地点资料随小程序版本发布，无需地图 API、定位授权或额外登录。

## 本版功能

- 按城市或省份搜索城市；记住上次选择。
- 搜店名、商圈、区县与地址；按吃饭、喝咖啡、住一晚、户外玩、逛一逛分类。
- 携宠条件多选取交集。来源未写明的条件不会作为肯定结果匹配。
- 查看位置、历史携宠条件、注意事项、原始来源链接、帖子显示时间与采集时间。
- 本机收藏；选最多 12 处地点生成微信分享清单。打开别人的清单不会自动修改自己的收藏。
- 分享单个地点或城市分类；失效地点与暂无数据城市有独立提示。

## 数据更新

资料输入为 `server/place-research/city-content.json`，城市目录为同目录 `city-targets.json`。本版 323 篇来源整理为 37 个城市、591 处地点线索，5 个无法确定具体名称的条目未纳入。

```sh
python3 server/build-outings.py
```

生成 `packages/outings/catalog.js` 和 `server/place-research/outings-build-report.json`。不要手工编辑生成的 catalog。

同城、规范化后同名的地点合并；保留分店名称，无法确认是否同一分店时不强行合并。地点 ID 从城市与名称计算，资料补充不会改变 ID；更名时需要注意旧分享链接和收藏兼容。

筛选字段在生成脚本的 `RULES` 中按「来源帖子 ID + 具体地点名」人工整理。新增规则应核对原始记录，不能把同一帖子里另一家店的条件套过来，也不能把“作者用了推车”当成“商家要求推车”。脚本发现规则对应的来源消失会报错。

## 当前边界

- 资料为公开出行分享的事实摘要，未联系商家核实；`verifiedAt` 均为 `null`。
- 拒绝进入、规则冲突和分店不明等记录会单独提示，不参与肯定条件的筛选。
- 不显示虚构评分、确认人数、距离或地图坐标。位置可复制，但没有地图导航。
- 收藏存在本机的 `paw_outing_favorites_v1`，不与宠物档案、演示数据或家庭共享混存。换设备暂不同步。
- 分享链接仅携带公开地点 ID，不包含个人信息。线上访问需发布包含该分包的小程序版本。
- 目前使用离线目录，新增采集资料需重新生成并发布。城市搜索中没有资料的城市显示“正在整理”。
